## Key Concepts

- **MCP (Model Context Protocol)**: Standardized interface between AI and security tools
- **Agentic loops**: Autonomous decision-making with human-in-the-loop safeguards
- **RAG for security**: Using retrieval-augmented generation for inventory and policy queries
- **Multi-agent systems**: Specialized agents collaborating on complex security tasks
- **Tool use**: AI models invoking security scanners, APIs, and infrastructure

## Prerequisites

- Python 3.11+
- Understanding of LLM APIs (Claude/Bedrock)
- Familiarity with at least one security scanning tool
- Basic understanding of MCP protocol
